# Calendar Trigger

When the user asks about their schedule, mentions being free/busy, asks "what's today look like", or refers to upcoming events:

1. Run `gcalcli agenda` to check the calendar before answering
2. Present the schedule clearly
3. If they want to add or change events, propose the change and wait for approval before writing (see `skill://google-calendar`)
