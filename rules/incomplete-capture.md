# Incomplete Work Capture

If a conversation ends and there are outstanding action items, unfinished tasks, or things the user said they'd do later:

1. Ask the user if they want to capture the incomplete items
2. If yes, create a task in Notion (see `skill://notion-create-task`)
3. Link it to the relevant Epic if one exists
